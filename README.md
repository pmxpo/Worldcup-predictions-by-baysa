# World Cup AI Dashboard

A stylish Streamlit dashboard for World Cup predictions using international match history.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud

1. Create a GitHub repo.
2. Upload `app.py`, `requirements.txt`, and the `data/results.csv` file.
3. Go to Streamlit Community Cloud.
4. Select the repo and set main file path to `app.py`.
5. Deploy and share the generated URL.

## Data

Default data file: `data/results.csv`.
You can also upload another `results.csv` from the dashboard sidebar.
